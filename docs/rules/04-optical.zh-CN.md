## 多尺寸检查

每份 Canonical SVG 都需要在视觉审核中确认小尺寸可读性。

- **必须**在 `16 / 20 / 24 / 32px` 检查 Canonical SVG。

## 视觉体积与居中

Keyline 和几何中心是起点，不是最终答案。圆形、三角形、箭头尖端和斜向轮廓可以轻微 overshoot；播放三角、箭头和不对称对象可以偏离数学中心。

- **应该**用并排比较和 Blur Test 判断视觉重量。
- **必须**让同类图标拥有接近的外部留白、墨色和负空间。
- **禁止**用无语义节点或重复描边补偿视觉重量。

## 间距与负空间

不设置单一全局最小间距。独立平行线、容器内部、Modifier、重叠轮廓和状态点分别评审。默认重量 `2` 下首先保证清晰，同时用 `0.5–2` 的公共 API 范围检查明显挤压。

## 交叉与遮挡

路径默认视为同一平面并直接交叉。只有语义明确要求前后关系时才创建断口，断口参考当前主线宽。遮挡不得依赖 mask、clipPath 或运行时裁剪来掩盖错误几何。

## 视角一致性

文件、设备、容器等同类对象使用统一视角。方向变体先旋转基础结构，再根据视觉重心做人工光学修正；修正后的图形仍是独立审核的 Canonical SVG。
