## 元数据职责

元数据描述图标“是什么、如何被发现、处于什么状态”，但不能改变视觉图形。

- **必须**让 `icons.json` 的键与图标语义名称完全一致。
- **必须**为每个图标提供唯一元数据对象。
- **禁止**在元数据中保存 SVG body、路径或视觉修正参数。
- **禁止**因修改元数据而格式化或改写 raw SVG。

提交元数据时，必填字段是 `title`、`titleZh`、`categories`、`subgroup`、`tags` 和 `aliases`。`description`、`related`、`variants`、`contributors`、`deprecated`、`publishedIn`、`updatedIn` 按实际情况填写。任何 `path`、`d`、坐标、颜色、描边或节点顺序都只属于 Canonical SVG，不得复制到 `icons.json`。

```json
{
  "bell": {
    "title": "Bell",
    "titleZh": "通知",
    "categories": ["objects"],
    "subgroup": "communication",
    "tags": ["objects", "对象", "communication", "沟通"],
    "aliases": ["notification"]
  }
}
```

## 资产关系

每个元数据键与一个 Canonical SVG 文件名一一对应。

- **必须**由生成器校验名称与文件集合一致。
- **禁止**手工声明没有对应正式 SVG 的图标。
- **禁止**让展示网站维护第二份资产可用性表。

## 标题

- **必须**提供非空英文 `title` 和中文 `titleZh`。
- **应该**使用产品团队能够直接理解的对象或动作名称。
- **应该**让标题与正式名称语义一致，但不必机械复制 kebab-case。
- **禁止**使用宣传文案、临时业务术语或不稳定缩写。

## 分类

`categories.json` 是分类 ID、顺序、中英文名称和描述的唯一注册表。

- **必须**让每个图标至少属于一个已注册分类。
- **必须**把 `categories[0]` 视为展示平台主分组。
- **可以**添加后续分类用于交叉筛选。
- **应该**保持分类数量稳定，仅在现有分类无法表达长期语义时新增。
- **禁止**让展示网站维护第二份图标分组清单。

## 标签

- **必须**至少提供一个标签，并保持数组无空值和重复值。
- **必须**把标签用于稳定归类，并至少包含图标的主分类 ID 和子分组 ID。
- **应该**同时提供分类与子分组的中英文标签，便于双语筛选和检索。
- **禁止**在标签中重复正式名称、别名或临时搜索词。
- **禁止**添加与图标无关的热门词、项目 ID、活动名或排序指令。

## 别名

- **可以**为同义词、旧名称和常见行业叫法增加 aliases。
- **应该**把名称之外的常见搜索叫法放入 aliases，而不是 tags。
- **必须**确保别名不与任何正式图标名冲突。
- **必须**确保每个别名在全库唯一，让搜索结果只有一个确定归属。
- **禁止**让别名自动生成组件、导出路径或重复 SVG。
- **禁止**用别名表达视觉风格或分类。

## 引用完整性

- **必须**确保 `related` 和 `variants` 目标都指向现有正式图标名。
- **禁止**让图标把自身声明为关联项或变体。

## 结构部件

`parts` 只声明 SVG 已经存在的稳定结构部件，不能创建或修正几何。只有 SVG 包含 `data-part` 时才提交 `parts`，且必须按文档顺序与所有 `data-part` 完全一致。

- **禁止**为了“以后可能会用到”预填 `parts`。
- **必须**让生成器拒绝 SVG 与 metadata 之间不一致的部件列表。

## 状态与版本

| 字段 | 用途 |
| --- | --- |
| `deprecated` | 标记不建议继续使用的正式名称 |
| `publishedIn` | 第一次进入公共包的版本 |
| `updatedIn` | 最近一次经过批准的视觉或语义更新版本 |

- **必须**把改名、弃用和视觉替换作为可追踪变更处理。
- **必须**让 `publishedIn`、`updatedIn` 使用语义化版本或 `null`，并让 `deprecated` 保持布尔类型。
- **应该**在正式发布时补齐版本字段。
- **禁止**静默删除已发布名称而不提供迁移说明。
