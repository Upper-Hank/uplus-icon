## 线宽体系

线性图标优先保留真实中心线描边。默认真源描边宽度为 `2`，消费端通过 `0.5–2` 的重量范围按比例调整整枚图标。

- **必须**让表达同一层级的线条使用一致线宽。
- **应该**使用 `stroke-width="2"` 作为正式真源默认值。
- **可以**在经过视觉审核后使用 `0.5–2` 内的其他真源线宽。
- **禁止**通过重叠相同路径制造局部加粗。
- **禁止**为了导出而把整套描边转换为大面积填充轮廓。

## 描边对齐

正式 SVG 默认使用居中描边：路径是描边中心线，线宽平均分布在路径两侧。

- **应该**优先使用居中描边，保持开放线条、封闭轮廓和运行时重量变化的行为一致且可预测。
- **可以**在需要固定外轮廓尺寸、保护内部负空间、表达遮挡关系或完成必要光学校正时使用内描边或外描边。
- **必须**通过负责人批准的最终路径位置或几何轮廓表达内外对齐，不得依赖兼容性不稳定的 `stroke-alignment` 属性，也不得由生成器自动偏移路径。
- **可以**在真实 stroke 无法稳定、准确表达所需内外边界时使用 `fill` 固化轮廓，但设计真源必须保留固定 `black`、透明背景和批准后的视觉重量；发布定义由私有适配流程转换为 `currentColor`。
- **必须**以真源默认宽度审核描边对齐；运行时调整 `weight` 后，内外边界可以随中心线向两侧变化，不承诺继续锁定某一侧边界。

## 开放端点

- **应该**对清晰可见的开放端点使用 `stroke-linecap="round"`。
- **可以**在切割线、容器边界或明确需要平切时使用 `butt`。
- **可以**在方形结构确有需要时使用 `square`。
- **必须**让端点选择来自语义，而不是设计工具默认值。

## 连接方式

- **应该**对柔和转折使用 `stroke-linejoin="round"`。
- **可以**为明确的尖角使用 `miter`，并检查缩小后的尖端长度。
- **可以**为切角结构使用 `bevel`。
- **禁止**让意外的 miter 尖刺超出画布或破坏视觉重量。

## 圆角一致性

- **必须**让同一图标中承担相同语义的圆角使用一致半径。
- **应该**让同系列容器、面板和矩形轮廓共享圆角语言。
- **可以**针对尺寸差异做光学校正，但不能产生肉眼可见的随机变化。
- **禁止**混用多个近似半径模拟手绘感。

## 重量与运行时 API

运行时以正式母版为基准，通过 `scale = weight ÷ 2` 计算图标重量。

```tsx
<CheckIcon size={24} weight={1.5} />
```

- **必须**把消费端重量限制在 `0.5–2`，越界输入向边界收敛。
- **必须**让所有真源描边宽度乘以同一 scale，以保留局部比例。
- **必须**让实心圆、椭圆和矩形围绕自身中心缩放，并同步缩放圆角。
- **禁止**自动变形实心 path 或其他复杂填充几何；必须列入设计复核清单。
- **禁止**使用 `vector-effect="non-scaling-stroke"`。
- **必须**让 `absoluteWeight` 同步缩放描边与受支持的实心基础图形；数值尺寸使用 `24 ÷ size`，字符串尺寸回退为相对重量。

## 检查清单

- 在 `0.5`、`1`、`1.5`、`2` 下观察轮廓和间隙。
- 在 12px 下确认圆角和端点没有形成噪点。
- 检查相邻线段是否因 round cap 产生非预期重叠。
