## 线宽体系

线性图标优先保留真实中心线描边。默认真源线宽为 `2`，消费端可以在 `0.5–2` 范围内覆盖。

- **必须**让表达同一层级的线条使用一致线宽。
- **应该**使用 `stroke-width="2"` 作为正式真源默认值。
- **可以**在经过视觉审核后使用 `0.5–2` 内的其他真源线宽。
- **禁止**通过重叠相同路径制造局部加粗。
- **禁止**为了导出而把整套描边转换为大面积填充轮廓。

## 开放端点

- **应该**对清晰可见的开放端点使用 `stroke-linecap="round"`。
- **可以**在切割线、容器边界或明确需要平切时使用 `butt`。
- **可以**在方形结构确有需要时使用 `square`。
- **必须**让端点选择来自语义，而不是设计工具默认值。

## 连接方式

- **应该**对柔和转折使用 `stroke-linejoin="round"`。
- **可以**为明确的尖角使用 `miter`，并检查缩小后的尖端长度。
- **可以**为切角结构使用 `bevel`。
- **禁止**让意外的 miter 尖刺超出画布或破坏视觉重量。

## 圆角一致性

- **必须**让同一图标中承担相同语义的圆角使用一致半径。
- **应该**让同系列容器、面板和矩形轮廓共享圆角语言。
- **可以**针对尺寸差异做光学校正，但不能产生肉眼可见的随机变化。
- **禁止**混用多个近似半径模拟手绘感。

## 缩放与运行时 API

生成器将真源 `stroke-width` 接入 CSS 变量，并保留真源值作为回退。

```tsx
<CheckIcon size={24} strokeWidth={1.5} />
```

- **必须**把消费端线宽限制在 `0.5–2`，越界输入向边界收敛。
- **必须**让描边随 SVG 尺寸缩放。
- **禁止**使用 `vector-effect="non-scaling-stroke"`。
- **禁止**让运行时线宽 API 修改纯填充区域。

## 检查清单

- 在 `0.5`、`1`、`1.5`、`2` 下观察轮廓和间隙。
- 在 12px 下确认圆角和端点没有形成噪点。
- 检查相邻线段是否因 round cap 产生非预期重叠。
