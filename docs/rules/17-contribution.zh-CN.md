## 提交前

贡献先说明语义、使用场景、与现有图标的关系及是否需要新资产。正式 SVG 必须由项目负责人提供或逐文件批准；截图、带辅助线设计稿和自动生成轮廓不进入 Raw 目录。

## 变更范围

- **必须**把元数据、生成器、运行时和站点改动拆成可审查的责任边界。
- **禁止**格式化、优化或批量改写不相关 Raw SVG。
- **应该**为 API 变化补充文档、类型检查和消费者示例。

## 审查材料

图标贡献需提供目标尺寸矩阵、明暗背景和同类并排对比。工程贡献需提供执行过的命令、包体影响及兼容性说明。Motion 贡献额外提供部件映射、Reduced Motion 和重复触发结果。
