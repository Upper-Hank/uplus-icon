## 描边与填充的边界

线性图标不等于完全禁止填充。点、状态、封闭实心区域和确实依赖面积表达的部分可以使用 fill。

- **必须**优先用真实 stroke 表达天然线性轮廓。
- **可以**为实心点、播放三角形、状态面、必要封闭区域，以及无法用真实 stroke 稳定表达的内外描边轮廓使用 fill。
- **应该**让填充区域与描边区域保持接近的视觉重量。
- **禁止**为减少节点或兼容导出而把整套描边转曲。

## 颜色

- **必须**在受保护的设计真源中只使用固定 `black` 和 `none` 表达单色视觉。
- **必须**由私有适配流程把属性值 `black` 确定性替换为 `currentColor`，并保持 `none` 不变。
- **禁止**让颜色适配改变 path、坐标、尺寸、viewBox、描边宽度、圆角、节点顺序或任何其他视觉与结构内容。
- **必须**让 Core、React 和网站只消费适配后的 `currentColor` 定义，使图标默认继承 CSS `color`，并允许消费者通过标准 `color` 属性覆盖。
- **禁止**维护第二份人工编辑的发布 SVG；适配结果只能是可复现的生成产物。
- **必须**让根 SVG 保持透明背景。
- **禁止**在设计真源中使用白色、十六进制色、RGB、渐变、`currentColor` 或调色板引用。
- **禁止**嵌入图片、字体或其他外部颜色资源。

## 允许的元素

```text
g path circle ellipse rect line polyline polygon
```

- **应该**优先使用 `path` 固化最终几何，尤其是圆角矩形、圆形和经过设计工具转换的复合轮廓，减少不同导出链路和渲染实现对基础图形参数的解释差异。
- **可以**在负责人确认跨目标环境渲染一致时保留 `circle`、`ellipse`、`rect`、`line`、`polyline` 和 `polygon`；它们属于允许的例外，不是默认导出形式。
- **必须**让转换后的 `path` 忠实保留批准图形的尺寸、圆角、坐标、描边和视觉结果，不得由生成器自动转换或重算。
- **禁止**以 path 优先为由把天然线条的真实 `stroke` 转换为填充轮廓；几何元素转换与描边转曲是两件不同的事。
- **可以**保留必要的 `fill-rule`、`opacity` 和简单旋转。
- **应该**删除无意义的嵌套 `g`、空元素和仅用于设计工具图层的结构。
- **禁止**使用 `text`、`image`、`use`、`foreignObject` 或嵌入内容。

## Path 合并与拆分

不以节点最少作为提交目标，也不要求所有几何合并为一个 `path`。拆分边界由视觉结构决定。

- **必须**把需要独立设置描边、填充、透明度、变换或动画时序的部分保留为独立元素。
- **必须**把不同语义部件保留为独立元素或独立 `g`；不得为了减少节点跨部件合并。
- **应该**让一条连续笔画保持为一个元素，避免没有语义价值的碎片化。
- **可以**合并同一部件内、绘制属性相同且永远同步运动的几何；合并不得改变视觉、子路径方向或填充规则。
- **禁止**由生成器自动合并、拆分或重排负责人批准的节点。

默认选择是“按语义部件拆分，部件内部保持简单”。需要路径绘制动画时，应保留可独立控制的连续笔画；需要整体淡入、缩放或旋转时，不需要仅为动画额外拆 path。

## 布尔与复合几何

- **可以**保留已经烘焙为普通 path 的布尔结果。
- **可以**使用 `fill-rule` 表达稳定的复合路径和孔洞。
- **应该**在进入真源前把简单遮罩或整画布裁剪转换为等价基础几何。
- **禁止**在正式真源中依赖运行时 `mask`、`clipPath`、`filter` 或 `defs`。
- **必须**在无法无损消除复杂结构时停止导入并请求成熟 SVG。

## transform

- **可以**保留最终几何确实需要的简单 rotate。
- **应该**在不改变视觉的前提下减少无意义 transform 链和嵌套坐标系。
- **禁止**由自动化工具回写或重算负责人已确认的 transform。

## 导出清理

进入 raw 前必须完成以下清理：

- **必须**删除背景矩形、网格、参考框、中心线、对角线、安全区和注释。
- **必须**删除脚本、事件属性、URL、data URI 和外部引用。
- **必须**删除不可见元素、重复节点和设计工具元数据。
- **禁止**让生成器自动修复不合规 SVG；它只能拒绝并报告。
