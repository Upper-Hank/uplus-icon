## 质量承诺

正式保证以 `24×24` 母版、默认线宽 `2`、推荐显示范围 `16–32px` 为核心。其他线宽用于发现明显崩坏，不代表等同视觉承诺。

## 自动化门禁

- **必须**验证 TypeScript、三个公共包和站点构建。
- **必须**验证逐图标入口不会打包完整图标表。
- **必须**验证生成可复现且不改写 Raw SVG。
- **必须**验证元数据名称、分类和路由的一一对应。
- **必须**验证 React 无障碍默认值、线宽边界和动态名称行为。
- **必须**验证原生 DOM 工厂和 Web Component 属性更新。
- **必须**检查发布包所需文档，并验证声明支持的最低 React Peer 版本。
- **必须**验证站点路由元数据、Sitemap 覆盖、SPA 回退和生产 JavaScript 预算。

## 视觉矩阵

尺寸检查 `16 / 20 / 24 / 32`，线宽覆盖公共范围内的代表值，至少检查明暗背景、Chrome/Safari/Firefox 和常见屏幕密度。检查识别度、视觉体积、负空间、交叉、断口及填充细节。

## 已知不可靠资产

资产未获负责人批准时，测试可以报告但不得自动修复 SVG。代码和文档改造可独立验证；正式发布门禁仍需在可信资产恢复后重新运行保真与视觉快照。
